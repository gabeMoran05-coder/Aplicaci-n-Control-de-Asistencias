Proyecto Django

Aplicacion Control de Asistencias

Sistema escolar para administrar alumnos, credenciales QR/NFC, registro de asistencia, calendario por estudiante y escaneo del profesor.

Panel escolar

Tabla de alumnos con filtros por nombre, grado, grupo y edad.

Escaneo profesor

Vista movil para registrar asistencia con QR, NFC o codigo manual.

Credencial

Plantilla imprimible con datos de emergencia, QR y soporte para NFC.

Nota: GitHub Pages muestra esta pagina estatica, pero no ejecuta Django. Para correr la aplicacion completa:
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
